### Question 1
The polar angle of interest can be computed:
$$
\theta = \arctan\left( \frac{2}{1} \right)= \arctan 2
$$
The magnitude is:
$$
\sqrt{ 1^{2}+2^{2} } = \sqrt{ 5 }
$$
And therefore:
$$
z = \left[ \sqrt{ 5 }e^{ -i\arctan(2) } \right] ^{3} = 5^{3 /2} \exp \{ -3i\arctan(2) \}
$$
Where I have chosen a negative angle because the complex value is negative, and so below the horizontal (real line).
### Question 2
$$
\exp \left\{ \ln \left[ (1-i)^{1-i} \right]  \right\} = \exp \left\{ (1-i)\ln(1-i) \right\}
$$
Recall that logarithms can be evaluated:
$$
\log w = \log|w| + i \arg w
$$
Therefore, for this logarithm we have:
$$
\ln(1-i) = \ln \sqrt{ 2 } + i \left( -\frac{\pi}{4} \right) + 2\pi k
$$
Where $k \in \mathbb{Z}^{\geq 0}$. And so all possible values are:
$$
\exp \left\{ (1-i)\left[ \ln \sqrt{ 2 } - \frac{\pi i}{4} + 2\pi k \right]  \right\}
$$
### Question 3
Cauchy-Riemann equations are:
$$
u_{x} = v_{y} \qquad v_{x} = -u_{y}
$$
For some function $f(z) = u(z)+iv(z)$. First, split the logarithm into the real and imaginary parts:
$$
\log z = \log|z| + i \arg z
$$
Define $x+iy$. Which transforms the above into:
$$
\log z = \log \sqrt{ x^{2}+y^{2} } + i \arctan\left( \frac{y}{x} \right)
$$
